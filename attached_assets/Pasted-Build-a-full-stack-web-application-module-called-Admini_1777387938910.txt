Build a full-stack web application module called **Administration & Talent Transformation Portal** with the following requirements:

## Core Concept

Create a **role-based access control (RBAC) system** with a primary admin user (e.g., [admin@horizon.com](mailto:admin@horizon.com)) who can manage users, permissions, and platform content. The system should also include a **Talent Transformation Roadmap feature** for workforce planning and skill development tracking.

---

## 1. Authentication & Roles

* Implement secure authentication (JWT or session-based).
* Default admin account: **[admin@horizon.com](mailto:admin@horizon.com)** (seeded in database).
* Support roles:

  * Admin
  * Manager
  * User

---

## 2. Role-Based Access Control (RBAC)

* Admin can:

  * Create/edit/delete users
  * Assign roles and custom permissions
  * Control access to modules (toggle features per role)
* Permissions should be **editable dynamically** (not hardcoded).
* Design a **permissions matrix UI**:

  * Rows: Features (Dashboard, Talent Plan, Reports, etc.)
  * Columns: Roles
  * Toggle switches for access control

---

## 3. Admin Dashboard

* Clean, modern UI
* Sections:

  * User Management
  * Role & Permissions Editor
  * Activity Logs (who changed what)
  * System Settings

---

## 4. Talent Transformation Roadmap Feature

Create a module called **Talent Plan**:

### Features:

* Define strategic goals (e.g., “AI Adoption”, “Cloud Migration”)
* Map required skills per goal
* Assign employees to transformation tracks
* Track:

  * Current skill level
  * Target skill level
  * Progress over time

### UI Components:

* Roadmap timeline view
* Skill gap analysis dashboard
* Employee progress cards
* Filters (by team, skill, role)

---

## 5. Data Model (suggested)

* Users (id, email, role, status)
* Roles (id, name)
* Permissions (id, key, description)
* RolePermissions (role_id, permission_id)
* TalentPlans (id, goal, description, timeline)
* Skills (id, name, category)
* EmployeeSkills (user_id, skill_id, current_level, target_level)

---

## 6. UX Requirements

* Intuitive admin controls (non-technical users)
* Responsive design
* Use charts for progress visualization
* Inline editing for permissions and talent plans

---

## 7. Tech Stack (flexible but suggested)

* Frontend: React + Tailwind
* Backend: Node.js / Express
* Database: PostgreSQL or MongoDB

---

## 8. Bonus Features

* Audit trail for admin changes
* Role templates (predefined permission sets)
* Export talent roadmap as PDF
* Notifications for skill milestones

---

## Expected Output

A working prototype with:

* Login system
* Admin panel with editable permissions
* Talent Transformation module with roadmap tracking
* Clean UI and scalable architecture

Focus on modular, maintainable code and clear separation between authentication, authorization, and business logic.
